# Notivelo

A native Android app for privately keeping and reading notification history from apps the user explicitly selects.

**Documentation-only portfolio showcase by Farook Fahath.**

## Features

- Explicit notification-access consent and app selection; no apps selected by default.
- Searchable local history, full-message reading, and per-app history controls.
- Capture pause, configurable retention, biometric/device-credential app lock, and encrypted local backup exports.
- Onboarding, light/dark appearance, and app-health guidance.

## Technology

Kotlin, Jetpack Compose, Room, AndroidX WorkManager, AndroidX Biometric.

## Current status

Unpublished Android application in development. Project documentation states that no Play Store submission or approval has occurred. Incoming notification delivery and successful system authentication still require manual device verification. Encrypted exports do not encrypt the live Room database.

## Scope and limitations

Local-only notification storage; no accounts, ads, tracking, backend, or Android INTERNET permission. Notification access cannot recover content that Android never exposes.
